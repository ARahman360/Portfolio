# Md Abdur Rahman Portfolio

A modern portfolio website for an Industrial Information Technology student at LAB University of Applied Sciences.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

1. Replace `your.email@example.com` in `app/page.tsx` with your real email.
2. Replace the LinkedIn placeholder link with your LinkedIn URL.
3. Put your real CV in `public/Md_Abdur_Rahman_CV.pdf`.
4. Replace or expand the project descriptions and add real project links when ready.
5. Deploy to Vercel.
